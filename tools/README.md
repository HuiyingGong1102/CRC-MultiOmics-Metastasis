# GLMY application

`GLMY.exe` is a Windows application developed and generated by our research
group for GLMY homology analysis. The bundled executable is included in the
repository and distributed under the MIT License; see [LICENSE](../LICENSE).

SHA-256 of the tested binary:
`8cc84c487e4b40ad08566c6ab6974392ea0a5125aa82244200afc5da3d739181`.

A formal application version has not yet been assigned in this repository.
Steps 01-04 do not require the application; step 05 invokes it automatically.
No separate GLMY installation is needed. Each network is analyzed in an
isolated temporary working directory to prevent output conflicts.
